Copilot CLI をインストールして会話を試したので、次はプロジェクトに最初の変更を加えます。変更は小さくします。ゲームのデータにはすでに星評価がありますが、ホームページのゲームカードには表示されていません。エージェントに評価を表示させ、変更をレビューして、最初のプルリクエストとしてマージします。

このレッスンでは、次の操作を行います。

- 機能ブランチで Copilot との会話を開始します。
- エージェントに小さな変更を依頼します。
- `/diff` で変更をレビューします。
- アプリを実行し、転送されたブラウザーで変更を確認します。
- 最初のプルリクエストを作成してマージします。

## シナリオ

Tailspin Toys の各ゲームには星評価があり、ゲーム詳細ページにはすでに表示されています。一方、ホームページのゲームカードに表示されるのはタイトル、カテゴリ、パブリッシャー、説明だけです。ウォームアップとして、各カードに既存の評価を表示させます。最初のセッションにちょうどよい、小規模で独立した変更です。

## 会話のしくみ

**会話**では、Copilot CLI を使ってタスクに取り組みます。Copilot app とは異なり、通常の CLI 会話では、専用の worktree ではなく、ターミナルで現在チェックアウトされているリポジトリと Git ブランチを使います。保存した会話に戻って同じやり取りを続けられますが、ファイルとブランチは通常の Git 状態としてディスク上に残ります。

会話には、プロンプトとエージェントの応答、ファイルを調べて編集するエージェントの操作、`/diff` で確認できる変更が表示されます。

## 会話を開始して変更を依頼する

機能の実装に向けて、新しい会話を始めます。

1. Codespace に戻ります。
2. まだターミナルを開いていない場合は、<kbd>Control</kbd>+<kbd>\`</kbd> (Mac) または <kbd>Ctrl</kbd>+<kbd>\`</kbd> (Windows/Linux) を押します。
3. まだ起動していない場合は、次のコマンドを実行して Copilot を起動します。

   ```bash
   copilot --yolo
   ```

4. スラッシュコマンド `/new` を入力し、<kbd>Enter</kbd> を押して新しいセッションを開始します。
5. 次のプロンプトを送信して変更を依頼します。

   ```plaintext
   各ゲームカードに、ゲームの starRating を 5 段階で表示してください。評価が null の場合は "No rating yet" と表示してください。カードのレイアウトは変えず、テストを追加して、関連するチェックを実行してください。
   ```

Copilot はプロジェクトを調べ、ゲームの詳細を表示するファイルを見つけて、必要なコードを作成します。これで Copilot CLI を使って新機能を追加できました。

## 差分をレビューする

小さな変更であっても、AI が生成した変更はマージする前にレビューします。Copilot CLI で変更を確認しましょう。

1. `/diff` を入力し、変更されたすべてのファイルを確認します。
2. 評価がある場合はゲームカードに数値が表示され、`starRating` が `null` の場合は `No rating yet` と表示されることを確認します。
3. テストが両方の状態を網羅していることを確認します。
4. Copilot が実行したチェックの結果を確認し、失敗があれば修正を依頼します。
5. レビューが終わったら、<kbd>Esc</kbd> を押して差分画面を閉じます。

> [!NOTE]
> Copilot を含む生成系人工知能 (AI) ツールは確率的に動作するため、生成されるコードは毎回異なる可能性があります。特定の実装と一致することではなく、動作を確認してください。

## 変更を確認する

コードを読んだだけで動作すると判断せず、Copilot に Web サイトを起動させ、Codespaces が転送するブラウザーで更新後のユーザー インターフェイス (UI) を確認します。

1. Copilot に次のプロンプトを送り、アプリを起動します。

   ```plaintext
   ブラウザーで星評価の変更を確認できるように、アプリを起動してください。URL を教え、サーバーは実行したままにしてください。
   ```

2. Codespaces でポート `4321` が利用可能と表示されたら、**Open in Browser** を選択します。
3. ゲームカードに 5 段階の評価が表示されることを確認します。
4. Copilot に戻り、次のプロンプトを送信して、起動したサーバーを停止します。

   ```plaintext
   起動した開発サーバーを停止してください。
   ```

## 最初のプルリクエストを作成してマージする

機能を作成できました。次はプルリクエスト (PR) を作成し、新しいコードをプロジェクトにマージします。

1. デフォルト エージェントに次のプロンプトを送り、変更をコミットします。

   ```plaintext
   レビュー済みの星評価の変更を、適切なコミットメッセージでコミットしてください。
   ```

2. `/pr create` を入力します。PR の作成時に Copilot CLI が既存のコミットをプッシュし、PR の URL を表示します。
3. <kbd>Command</kbd> (Mac) または <kbd>Ctrl</kbd> (Windows/Linux) を押しながら、Copilot CLI に表示された URL を選択して PR を開きます。
4. 変更されたファイルとチェックの結果を確認します。
5. 準備ができたら **Merge pull request** を選択し、マージを確定します。
6. Codespace に戻り、`/exit` を入力して Copilot CLI を終了します。
7. ローカルの `main` を更新します。

   ```bash
   git checkout main
   git pull
   ```

## まとめと次のステップ

- エージェントにゲームカードの小さな変更を依頼しました。
- `/diff` で変更をレビューしました。
- アプリを実行し、転送されたブラウザーで星評価を確認しました。
- 最初のプルリクエストを作成してマージしました。
