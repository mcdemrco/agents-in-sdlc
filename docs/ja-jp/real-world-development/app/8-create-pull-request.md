フィルター機能の実装、指示の更新、スキルの更新、品質保証 (QA) プロファイル、テストをひとつのブランチに保存しました。これらをまとめてレビューし、プルリクエストを作成します。星評価のプルリクエスト (PR) は自分でマージしましたが、今回は **Agent Merge** にプロセスを管理させます。

> [!NOTE]
> 通常は、機能、指示の更新、スキルの更新、QA エージェントを複数の PR に分けます。ワークショップを簡略化するため、フィルター機能と品質改善の作業をひとつのセッションとブランチにまとめ、この PR に含めました。

このレッスンでは、次の操作を行います。

- Agent Merge とマージのライフサイクルを自動化する方法を学びます。
- 機能全体の PR と検証の根拠を確認します。
- レビュー後に Agent Merge を許可し、PR がマージされたことを確認します。

## シナリオ

フィルタリング機能のワークフローでは、Copilot を使って機能を計画、実装、検証しました。Tailspin Toys は、マージを許可する権限を開発者が管理したまま、残りの PR 作業を自動化したいと考えています。

## Agent Merge について

**Agent Merge** は、GitHub Copilot app でプルリクエストをマージ可能にするための残りの作業を自動化します。有効にすると、アプリのセッションがプルリクエストを読み取り、継続的インテグレーション (CI) のチェック失敗の修正、レビューコメントへの対応、必要に応じたリベースなど、マージを妨げている問題を解決します。その後、GitHub で許可され次第マージします。バックグラウンドで動作し、アプリを再起動しても継続し、プルリクエストがマージされると自動的に停止します。

これまでは **Merge pull request** を自分で選択していました。Agent Merge に任せることもできますが、コードの編集とマージには引き続き明示的な許可が必要です。マージを許可する前に、エージェントが許可されている操作と作業内容を確認してください。

## Agent Merge を使って PR を管理する

コードの作成とレビューが終わったら、Agent Merge に PR の残りの作業を任せます。

1. エージェント選択メニューで **Default agent** を選択します。
2. **Create PR** の横にあるドロップダウンを選択します。
3. **Agent Merge** を選択します。ボタンが **Agent Merge** に変わります。
4. **Agent Merge** ボタンを選択して処理を開始します。ドロップダウンの選択だけでは始まりません。

Agent Merge が作業を開始します。次の処理を行います。

- タイトルと説明を付けてプルリクエストを作成します。
- issue からセッションを開始した場合は、説明の本文で関連する issue を参照します。
- リベースを行うか、ターゲット ブランチとのマージ競合に対処します。
- 継続的インテグレーションの処理を監視し、すべてのチェックが成功することを確認します。
- ほかの開発者や Copilot code review からのフィードバックを確認し、コメントを解決するために変更を加えます。
- すべてのチェックが成功した後、PR を自動的にマージすることもできます。

すべてのチェックが成功した後、Agent Merge に PR もマージさせます。

5. マージを許可する前に、PR の差分と検証の根拠をレビューします。
6. **Agent Merge** の横にあるドロップダウンを選択します。
7. **Merge pull request** の横にチェックが付いていることを確認します。
8. エージェントに明示的にマージを依頼します。

   ```plaintext
   必須のチェックと承認がすべて成功したら PR をマージしてください。リポジトリの保護は回避しないでください。
   ```

9. 作業の進捗を確認し、報告された問題に対処します。続行する前に、PR の状態が **Merged** であることを確認します。マージの許可を有効にしたことやエージェントが実行中であることは、マージ完了の確認にはなりません。

> [!IMPORTANT]
> Agent Merge は、リポジトリの保護や権限不足を回避しません。続行する前に、それらの問題に対処してください。

## まとめと次のステップ

コードの生成、テストと検証、プルリクエストの処理など、開発プロセスの一部を自動化しました。このレッスンでは、次の操作を行いました。

- Agent Merge とマージのライフサイクルを自動化する方法を学びました。
- 機能全体の PR と検証の根拠を確認しました。
- フィルタリングの PR を作成しました。
- レビュー後にのみ Agent Merge を有効にし、PR がマージされたことを確認しました。
