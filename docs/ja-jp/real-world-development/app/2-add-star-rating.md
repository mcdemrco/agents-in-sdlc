ワークスペースを確認し、クイックチャットを試したので、次は**エージェント セッション**を開始し、プロジェクトに最初の変更を加えます。変更は小さくします。ゲームのデータにはすでに星評価がありますが、ホームページのゲームカードには表示されていません。エージェントに表示させ、変更をレビューして、最初のプルリクエストとしてマージします。

このレッスンでは、次の操作を行います。

- エージェント セッションを開始し、セッションの構成を確認します。
- エージェントに小規模で対象を絞った変更を依頼します。
- ワークスペースの差分ビューで変更をレビューします。
- アプリをローカルで実行し、ブラウザーで変更を確認します。
- 最初のプルリクエストを作成してマージします。

## シナリオ

Tailspin Toys の各ゲームには星評価があり、ゲーム詳細ページにはすでに表示されています。一方、ホームページのゲームカードに表示されるのはタイトル、カテゴリ、パブリッシャー、説明だけです。最初のセッションのウォームアップとして、各カードに既存の評価を表示させます。小規模で独立した変更で、最初のセッションに適しています。

## セッションのしくみ

**セッション**は、独立したワークスペースでエージェントと会話する作業単位です。各セッションには専用の git worktree とブランチが用意されるため、たとえば一方で機能を追加し、別のセッションでバグを修正しても、変更が競合しません。セッションはサイドバーでリポジトリごとにグループ化され、選択すると切り替えられます。

セッションには、エージェントとの**会話**、ファイルを調べて編集するエージェントの**ツール アクティビティ**、差分付きの**変更済みファイル**一覧が表示されます。

## セッションを開始して変更を依頼する

新しいセッションを開始し、プロジェクトの調査と機能の実装に取りかかります。[アプリを設定したとき][prior-lesson]に、GitHub リポジトリからプロジェクトを追加しました。そのリポジトリ用のセッションを作成して、変更を依頼します。

1. GitHub Copilot app に戻ります。アプリを閉じている場合は開きます。
2. サイドバーの上部にある **+** を選択してセッションを開始します。
3. リポジトリに `tailspin-toys` を選択します。
4. プロンプト ボックスの下で **new working tree** と **Interactive** モードを選択し、次のプロンプトで変更を依頼します。

   ```plaintext
   ゲーム一覧ページの各ゲームカードに starRating を 5 段階で表示してください。評価が null の場合は "No rating yet" と表示してください。カードのレイアウトはそのままにし、テストを追加して、関連するチェックを実行してください。
   ```

5. <kbd>Enter</kbd> を押して、Copilot にプロンプトを送信します。

Copilot app はプロジェクトの分離されたコピーである新しい worktree を作成してから、プロジェクトを調べます。新機能に必要なファイルを見つけ、コードを作成します。これで Copilot app を使って機能を追加できました。

## 差分をレビューする

人工知能 (AI) が生成した変更は、小さなものであってもマージする前にレビューします。Copilot app で変更を確認しましょう。

1. アプリの右上隅にある **Toggle review panel** を選択します。開いたパネルで **Changes** を選択し、変更されたファイルとその差分を確認します。

   ![Create PR ボタンの右側に Toggle review panel ボタンがある、GitHub Copilot app の上部ツールバー](../../../_images/app-2-review-panel.png)

2. ゲームの詳細を表示する中心的なファイル `GameCard.astro` にコードが追加されていることを確認します。評価がある場合は表示し、`starRating` が `null` の場合は "No rating yet" を表示する、次のような小さなブロックです。

   ```astro
   {game.starRating !== null ? (
       <span class="text-xs font-medium px-2.5 py-0.5 rounded bg-amber-900/60 text-amber-300" data-testid="game-rating">
           ★ {game.starRating} / 5
       </span>
   ) : (
       <span class="text-xs font-medium text-slate-500" data-testid="game-rating-empty">
           No rating yet
       </span>
   )}
   ```

> [!NOTE]
> Copilot は、すべての生成 AI ツールと同様に確率的に動作するため、生成コードは上記と異なる場合があります。似た実装になるはずです。

## 変更を確認する

ブラウザーを開く前に、エージェントが実行した自動チェックをレビューします。数値の `starRating` と、`null` の場合の代替表示の両方をテストで確認していることを確かめます。前提条件が不足していたり、チェックがスキップされていたりする場合は成功ではありません。インストールを求められた場合は内容を確認してから承認します。

コードを読んだだけで動作すると判断せず、Copilot に Web サイトを起動させ、更新されたユーザー インターフェイスをブラウザーキャンバスで確認しましょう。

> [!TIP]
> キャンバスは、Copilot app 内で利用できるインタラクティブなウィジェットです。後の演習ではカスタムキャンバスを確認して作成しますが、ここでは組み込みのブラウザーキャンバスを使います。

1. 次のプロンプトを送り、アプリを起動してブラウザーキャンバスで開くよう依頼します。

   ```plaintext
   アプリを起動して、ブラウザーキャンバスで開いてください。
   ```

2. しばらくするとアプリが起動し、Copilot app 内にブラウザー ウィンドウが開きます。
3. 評価があるゲームカードに、5 点満点の評価が表示されることを確認します。
4. 確認が終わったら、次のプロンプトを送り、このセッションで起動した開発サーバーを停止します。

   ```plaintext
   開発サーバーを停止して、ブラウザーキャンバスを閉じてください。
   ```

## 最初のプルリクエストを作成してマージする

機能を作成できました。次はプルリクエスト (PR) を作成し、新しいコードを既存のコードベースにマージします。

1. 右上隅の **Create PR** を選択します。
2. 求められたら **Sign in with your browser** を選択し、画面の指示に従って認証します。
3. PR を作成する前に、リポジトリ ポリシーにより関連する issue が必要だと Copilot が説明した場合は、その手順に従うよう確認します。
4. Copilot が PR を作成します。
5. チャットのすぐ上にある **PR** バブルを選択し、レビューパネルで PR を開きます。必要に応じて内容をレビューします。
6. 準備ができたら **Ready to merge** を選択します。
7. 表示されたダイアログで **Merge pull request** を選択して、PR をマージします。

## まとめと次のステップ

GitHub Copilot app を使って最初の変更をリリースしました。このレッスンでは、次の操作を行いました。

- エージェント セッションを開始し、その構成を確認しました。
- エージェントにゲームカードの小規模で対象を絞った変更を依頼しました。
- ワークスペースの差分ビューで変更をレビューしました。
- アプリをローカルで実行し、ブラウザーで星評価を確認しました。
- 最初の PR を開き、チェックをレビューして、自分でマージしました。
