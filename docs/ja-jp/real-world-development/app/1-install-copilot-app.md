**[GitHub Copilot app][about-copilot-app]** は、エージェント主導の開発に使用するデスクトップ アプリです。GitHub Copilot CLI を基盤とし、GitHub とネイティブに統合されているため、リポジトリ、ブランチ、継続的インテグレーション (CI) パイプラインをすぐに利用できます。すべての作業を自分で行うのではなく、複数のエージェントを個別の分離されたワークスペースで並行して動かし、繰り返し作業を自動化するワークフローに適しています。Node.js のインストールとプロジェクトのコピーが完了したので、次はアプリをインストールしてリポジトリを接続します。

このレッスンでは、次の操作を行います。

- GitHub Copilot app をインストールしてサインインします。
- GitHub リポジトリからプロジェクトをアプリに追加します。
- テンプレートで用意されたバックログなど、ワークスペースの構成を確認します。
- クイックチャットを試し、アプリについて質問します。

## シナリオ

チームは、増え続けるバックログに対応するため人工知能 (AI) エージェントを導入しています。Copilot app では、issue の選択、エージェントの実行、変更のレビュー、プルリクエストのマージを一か所から指示できます。このレッスンでは、アプリをインストールしてリポジトリを接続し、プロジェクトについての会話を始められるようにします。

> [!NOTE]
> 対象となる Copilot プランが必要です。Copilot Free、Copilot Student、または有料プラン (Pro、Pro+、Business、Enterprise) を利用してください。Copilot Business または Copilot Enterprise を使用している場合、管理者が **GitHub Copilot app** ポリシーを有効にしておく必要があります。

## GitHub Copilot app をインストールして設定する

GitHub Copilot app を使うには、まずアプリをインストールします。Windows、macOS、Linux 向けのバージョンがあります。アプリをインストールして認証し、Tailspin Toys リポジトリを追加します。

1. ブラウザーで [GitHub Copilot app のランディング ページ][download-app]を開きます。
2. 使用しているプラットフォーム向けのアプリをダウンロードし、ページの手順に従ってインストールします。
3. インストール後、アプリを開きます。
4. **Sign in to GitHub** を選択し、画面の指示に従って認証します。データ所在地を指定する GitHub Enterprise Cloud を使う場合は、**Use GitHub Enterprise** を選択し、求められたら `*.ghe.com` のホスト名を入力します。GitHub Enterprise Server はサポートされていません。
5. オンボーディングでリポジトリを選択する画面が表示されたら、テンプレートから作成した Tailspin Toys リポジトリを選択します。リポジトリ選択をスキップし、オンボーディング後に追加することもできます。
6. テーマを選択するよう求められたら選び、オンボーディングを完了します。
7. サイドバーの **Sessions** の下にリポジトリが表示されているか確認します。すでに表示されていれば、再度追加する必要はありません。
8. リポジトリがまだ接続されていない場合は、**Sessions** の横にある **+** を選択して新しいセッションを作成し、**Add GitHub repository** を選択します。前提条件のレッスンで記録した所有者名とリポジトリ名を使います。
9. リポジトリがサイドバーに表示されることを確認します。ここで使うレイアウトでは、`tailspin-toys` などのリポジトリ フォルダーが **Sessions** の下にグループ化され、各リポジトリの下に個別のセッションが表示されます。

## ワークスペースの構成を確認する

プロジェクトを接続したら、アプリの使い方を確認します。サイドバーは主に次の領域で構成されています。

- **New** - 新しい Copilot チャット セッションを開始します。
- **Pull requests** - アプリと GitHub のネイティブな統合でプルリクエストを表示します。アプリを離れずに、プルリクエストの閲覧や絞り込み、継続的インテグレーション (CI) の状態確認、レビューができます。
- **Issues** - issue を閲覧および絞り込み、issue からセッションを開始できます。
- **Automations** - スケジュールまたはオンデマンドで実行する、保存済みのエージェント タスクです。To Do リストの管理、定期的な保守、その他の面倒な作業を任せるのに役立ちます。まとめでは次のステップとして紹介しますが、追加の演習ではありません。
- **Customize** - Model Context Protocol (MCP) サーバー、プラグイン、スキルなどを追加し、Copilot app に機能を追加します。Playwright MCP の設定で使用します。
- **Chats** - 独自のブランチやワークスペースを必要としない質問やブレインストーミング向けの、軽量な会話です。最初のチャットを始めると表示されます。表示されない場合は、**Sessions** の横にある **+** を選択してチャットを開始します。
- **Sessions** - リポジトリ フォルダーと、その中のエージェント セッションをまとめます。`tailspin-toys` などのリポジトリ名を選択するとリポジトリ画面が開き、その下のセッションを選択すると会話に戻ります。セッションはそれぞれ独立したワークスペースで動くため、変更を競合させずに複数のセッションを同時に実行できます。最初のセッションは星評価を追加する際に開始します。

ワークショップを進めながら、ワークスペースの各機能を確認します。

> [!TIP]
> 迷ったときは Copilot に質問しましょう。操作方法が分からない場合や、何かが可能か知りたい場合は、Copilot が案内してくれます。

### 用意されたバックログを確認する

ほとんどのプロジェクトにはバックログがあり、Tailspin Toys も例外ではありません。テンプレートから作成したときに用意されたバックログを確認します。

1. サイドバーの **Sessions** の下で、個別のセッションではなく Tailspin Toys のリポジトリ フォルダーを選択します。その後、リポジトリの上部ナビゲーションにある **Issues** を選択します。
2. issue 番号を決めつけず、次のタイトルを探します。
   - Allow users to filter games by category and publisher
   - Update our repository coding standards
3. issue を選択して詳細を読みます。各 issue からエージェント セッションを開始できます。小規模な最初の変更が終わった後、フィルタリングの issue から作業を始めます。

> [!NOTE]
> **Issues** と **Pull requests** の一覧は自動的に絞り込まれ、Copilot app に追加したリポジトリの項目だけが表示されます。ほかのリポジトリの作業項目を表示する場合は、そのリポジトリをアプリに追加してください。

## クイックチャットを試す

アプリの機能について質問すると、アプリに慣れることができます。この用途には **クイックチャット**が適しています。クイックチャットはブランチや worktree を作成せずに質問やブレインストーミングができるため、セッションを必要としない、すぐに終わる質問に向いています。

1. サイドバーで **Chats** の横にある **+** を選択し、新しいチャットを開きます。**Chats** がまだ表示されない場合は、**Sessions** の横にある **+** を選択して最初のチャットを開始します。その後 **Chats** が表示されます。
2. アプリのセッションのしくみについて質問します。

   ```plaintext
   GitHub Copilot app は worktree をどのように使いますか。
   ```

3. 会話ビューで回答を読みます。各セッションが専用の分離された git worktree で実行されるため、複数のエージェントを並列に動かしても変更が競合しないことが分かります。会話は続けることも、新しいチャットを始めることもできます。

## まとめと次のステップ

GitHub Copilot app をインストールし、プロジェクトを接続して、ワークスペースを確認しました。次のことを学びました。

- アプリをインストールして GitHub にサインインしました。
- GitHub リポジトリからプロジェクトを追加しました。
- ワークスペースを確認し、**Issues** で用意されたバックログを見つけました。
- クイックチャットで短い質問をしました。

次は[最初のエージェント セッションを開始し][next-lesson]、ゲームカードに星評価を表示します。
