Copilot Chat のエージェントモードでは、Copilot がコードベースを調べ、変更を提案し、ファイルを編集してコマンドを実行します。VS Code では作業がリアルタイムで進むため、ツールの呼び出しやファイルの編集を確認できます。差分を一つずつレビューし、変更を適用または取り消し、追加のプロンプトを送って作業を修正・拡張できます。エディターを離れる必要はありません。

この演習では、次の操作を行います。

- アクセシビリティ エージェントの作業をリアルタイムで監視します。
- 提案されたファイルの編集をレビューして適用します。
- セッションの途中でエージェントに指示し、ハイコントラストに加えてライトモードのトグルを追加します。

## シナリオ

[演習 4][previous-lesson]で使ったアクセシビリティ カスタムエージェントは、ハイコントラスト モードを実装しています。作業中、デザイン チームから追加の要望がありました。既定のテーマが暗すぎると感じるユーザーのために、ライトモードのトグルも追加したいとのことです。最初から新しい会話を始める代わりに、進行中のセッションに追加の作業を依頼します。

## Copilot の進捗を監視する

Copilot Chat ビューには、エージェントが行う各手順が表示されます。調べたファイル、実行したコマンド、提案された編集を確認できます。ファイルの編集は差分と **Keep** / **Undo** の操作とともにチャットに表示されます。

1. 演習 4 で使った Copilot Chat ビューに戻ります。
2. エージェントが作業する様子を確認するため、チャットをスクロールします。ファイルの読み取りや編集、実行を求められたターミナル コマンドが表示されます。
3. エージェントがファイルの編集を提案すると、差分が表示されます。
   - **Keep** を選択すると変更を適用します。
   - **Undo** を選択すると変更を取り消し、エージェントにもう一度作業させます。
4. チャット上部の **Files changed** を開き、セッション中にエージェントが変更したファイル全体を確認することもできます。

> [!NOTE]
> ターミナル コマンドの実行など、ツールの使用許可を求められると、エージェントは一時停止して **Allow** を表示します。内容を確認し、許可してよいコマンドだけを承認してください。

5. エージェントがハイコントラスト モードの実装を終えるまで待ちます。最後に変更の概要が表示されます。

## ライトモードを追加するようエージェントに指示する

ハイコントラスト モードができたら、同じ会話でライトモードのトグルも追加します。同じチャット セッションを続けることで、エージェントは先ほどの作業、変更したコンポーネント、スタイルの方針、local storage の使い方を引き続き参照できます。

1. Copilot Chat の入力欄に、次の追加プロンプトを送信します。

   ```plaintext
   ありがとうございます。ハイコントラストのトグルと並べて、ライトモードのトグルも追加してください。   ライトモードも同じパターンに従い、local storage で設定を保持して、同じユーザー インターフェイス (UI) の領域から利用できるようにしてください。ユーザーはハイコントラストとライトモードを個別に有効にできる必要があります。
   ```

2. エージェントが先ほどの変更を調べ、ライトモードの追加を提案する様子を確認します。
3. ハイコントラスト モードのときと同様に、新しい編集を一つずつレビューし、差分ごとに **Keep** または **Undo** を選択します。
4. エージェントの方向が希望と異なる場合は、チャット入力欄の横にある **Stop** ボタンで停止し、追加の説明を送ります。

> [!TIP]
> 進行中のセッションに指示すると、最初から作業をやり直すよりもすばやく調整できます。たとえば「カスケーディング スタイル シート (CSS) を簡潔にして、セレクターの重複ではなく CSS 変数を使う」「トグルを追加するのではなく、既存の設定パネルにライトモードを組み込む」「両方のトグルにキーボード ショートカットも追加する」と依頼できます。

## 変更されたファイルをレビューする

作業をコミットする前に、エージェントが変更したファイルを確認します。

1. VS Code で **Source Control** ビューを開きます。
2. 変更されたファイルの一覧を確認します。Astro コンポーネント、スタイル、関連テストなどが更新されています。
3. 変更されたファイルをいくつか開き、差分を確認します。カスタムエージェントのアクセシビリティ パターン、Accessible Rich Internet Applications (ARIA) 属性、キーボード操作、セマンティック HTML、local storage による設定の保存が反映されていることを確認します。
4. 内容に問題がなければ、Source Control パネルから変更をステージしてコミットします。次のレッスンで公開します。

## まとめと次のステップ

Copilot Chat のエージェントモードを使い、進行中のセッションを監視して方向付けました。編集を確認しながら適用または取り消し、会話のコンテキストを保ったまま追加の作業を依頼しました。

この演習では、次のことを確認しました。

- エージェントの作業をリアルタイムで監視しました。
- 個々のファイル編集を適用または取り消しました。
- 追加プロンプトで進行中のセッションを調整しました。
